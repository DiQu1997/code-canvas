# 机器图舞台：写 sglang 一屏时碰到的问题（都已绕开，没改舞台代码）

1. **分组框不能只在手机上出现。** `group(label, d=None, m=[...])` 报 BuildError「d 必须给」；给 `[0,0,0,0]` 能过，但桌面左上角会冒出一个孤零零的标签。
   场景：手机竖排时「主进程」被拆成去程、回程两段，需要两个框；桌面只要一个。绕法：第二个框的 d 和第一个完全重合、标签同名，桌面上看起来是一个。
2. **框宽 155 时，`name` + `code` 基本总是折成两行**，小图被挤掉。最后所有框都去掉了 `code`，类名挪进说明卡第一句。想要的是 code 单独一行小字、或允许只在桌面显示 code。
3. **「为什么」图层框底那个等级小标取的是说明卡 why 栏第一条 note 的等级**，和框底 `why=` 那句短话无关。短话写的是另一条 note 的内容时，小标会标错（比如短话是推断，小标却写「注释」）。只能靠手动调整 note 顺序 / 改短话让两者对上。想要：`why=` 可以带等级，或直接指定对应哪条 note。
4. **g_kv 值太长时直接省略号截断，`--check` 不报。** 比如 GPU 框里「算 [B,A] decode」显示成「算 [B,A] deco…」。
