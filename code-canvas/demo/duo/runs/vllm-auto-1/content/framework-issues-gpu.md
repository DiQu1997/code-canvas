# 舞台问题（gpu 讲解员）

1. **手机上沿侧边绕行的长回线，标签默认落在线的中点，正好压在中间的框上。**
   复现：手机竖排 8 个框，`wire('w_post', 'samp', 'state', …, mfs='r', mts='r')`（从第 7 个框右边绕回第 2 个框），`--check` 报「线标签压在部件 fwd / ems 上」。
   绕开：用 `mlp` 手工把标签放进两个框之间的空隙。希望自动避让能把侧边线的标签挪进最近的框间空隙。

2. **缺一种「时间线 / 泳道」小图。** 这一层最想画的是三条并排时间线（CPU 主线程 / 主 stream / copy_stream），
   让读者看见「CPU 发射 S2 时 S1 还在 GPU 上跑」「S2 拼输入内核排在 S1 post_update 后面」。机器图只能画空间上的
   部件和数据流，时间先后只能靠推演一步步说。`g_raw` 理论上能画，但要自己保证尺寸、没有校验，这一趟没冒险。
