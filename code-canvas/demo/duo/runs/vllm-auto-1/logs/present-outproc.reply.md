## 4. 推断和不确定的地方
- 标了「推断」的「为什么」：扣字为什么是「长度 − 1」；stop 串为什么在前端判；单槽合并的好处和为什么不用加锁；`num_prev_tokens` 必须先取；logprobs 要在截短之后处理；`lo=1` 的含义；`cumulative_logprob` 为什么取最新；「只按长度扣、不看内容」。
- 有一处底稿行号偏了：`del output.new_token_ids[num_kept:]` 底稿写的是第 913 行，实际在第 910 行，我用了 910。
- `stream_interval` 在 CUMULATIVE 模式下疑似失效，这是研究员读代码得出的、没跑过，我标成了「观点」。
- 底稿缺、因此没写的：块大小为什么是 128；为什么每块发一次 abort 而不是整包发一次；`DecodeStream` 内部怎么做（外部 Rust 库，不在仓库里）；信箱换成单槽的动机（提交正文是空的）；chat 协议层收到 `text=""` 的包时会不会发一个空的 delta。最后这条我刻意没写客户端会看到什么。
