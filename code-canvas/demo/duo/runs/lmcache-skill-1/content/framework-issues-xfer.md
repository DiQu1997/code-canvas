# 舞台问题（讲解员，「传输模块」下一层）

1. 锚点扩展名白名单（build.py `REF_RE`）不含 `.cpp` / `.cu` / `.cuh`。本框的关键机制有一半在 `csrc/cuda/*.cpp|.cuh|.cu`
   （驱动线程上的 host 回调、拷贝内核的平铺与 skip），说明卡和 `note(ref=...)` 里没法给这些锚点；写成 `` `csrc/cuda/completion_recorder.cpp:28-33` ``
   会 WARN「像锚点但扩展名不在识别范围内」。
   最小复现：任意说明卡条目里写 `` `csrc/cuda/completion_recorder.cpp:28` ``。
   绕开：说明卡里只写「C++ 源码见下一层」，把这些文件放进源码页的 `code(...)`（`code` 不查扩展名，能正常取行）。

2. 手机上「跨过中间框」的长连线只能走左右两侧的空白（`mfs/mts='l'|'r'`）。贝塞尔外鼓最多约 67px，所以框得让出两边各 ~70px 边距，
   框宽只剩 200；侧边线标签只放得下 3–4 个字，「为什么 / 易混点」图层的线上短句只好压成三个字。
   想要的：连线能按正交折线绕开框，或者手机上允许某条线只在桌面显示。
