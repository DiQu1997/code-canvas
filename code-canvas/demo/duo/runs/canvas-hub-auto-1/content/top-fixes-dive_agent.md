# 顶层需要改的地方（来自 dive_agent 这一趟，以 manuscript-dive_agent.md 为准）

1. **部件 `agent` 的说明卡，「怎么设计的」第 4 条**
   - 原话：「它会自己跑 validate / check_refs / embed / render 自查，还会用 `reader_check.py` **再起一个 claude**……来挑错。」
   - 问题：「会」说成了必然。提示词里自查（渲染、截图、reader_check）是建议口吻，SKILL 说 reader_check「强烈建议至少一轮」，没有任何东西检查做没做（底稿 §2.1 表「做几轮 reader_check：半死」、§2.6「轮数没有上限，也没有任何东西强制至少一轮」）。
   - 建议：改成「通常会自己跑……；提示词还**建议**用 `reader_check.py` 再起一个 claude……（没有东西强制）」。

   - 建议：note 改成「prompt 把完成标准定成 SKILL §1 的六条：第一次接触代码库的读者只看画布就能做到」，q=「完成的标准是 SKILL 第 1 节」，ref=`serve.py:663`；reader_check 另说是建议。
