# 舞台问题（讲解员 · dive_post 这一趟）

1. **`--check` 量不到小图里被截断的值**
   - 现象：手机版宽 140 的框里放 `g_kv`，值太长时显示成「9 代码…」「preem…」（省略号截断），`--check` 报 0 条，只有看截图才发现。
   - 最小复现：`part('x', 'x', [0,0,250,170], m=[8,8,140,170], glyph=g_kv([('cards', '9 代码 + 1 状态'), ('refs', 'preempt 行号 72→75')]))`。
   - 绕法：把值缩短到约 6 个汉字以内。希望 `--check` 对 glyph 内文字溢出 / 省略也报一条 LAYOUT。

2. （小）推演条上 beat 的序号是自动加的圆圈数字；标题里自己再写 ①②… 会出现「② ① embed」这样的双序号。不是 bug，但 SCENE.md 可以提一句「标题别自己编号」。
