# 给顶层讲解员：「读者浏览器」相关的几处修正（依据：research/manuscript-dive_render.md）

1. **部件 `view` 的小图** `g_kv([('col 0 → x', '40'), …])`
   - 原话：`col 0 → x` = `40`
   - 为什么不对：nano-vllm 画布有一张 `corner: nw` 的背景 note `bg0`，`hasLeftNotes` 为真，col 0 的 x = 40 + 250 + 80 = **370**（底稿 §0「对上一趟顶层图的一处需要修正的地方」、§2.2、§6 第 1 条）。
   - 建议：改成 `('col 0 → x', '370')`，或换成不依赖画布的写法（如 `('x', '按列累加')`）。

2. **推演第 10 步「读者打开，浏览器排版」**
   - 原话：「浏览器 `layout()`：col 0 的 x = **40**」
   - 为什么不对：同上，这张画布 col 0 在 370（底稿 §2.2）。
   - 建议：「col 0 的 x = **370**（画布左上有一张角落 note，先让出 330 的 note 区）」。

3. **推演第 10 步** 「按 ▶ 进入第 ① 步：4 张卡聚焦、4 根线点亮」
   - 说法不准：哪张卡亮由这一步点亮的**线的两端**决定，不是 focus；镜头框的是 `step` 卡第 2–5 行，不是 4 张卡（底稿 §2.5「暗不暗看线不看 focus」、§2.6）。这一步数字恰好一致，但「聚焦」容易让读者以为镜头框住了 4 张卡。
   - 建议：「按 ▶ 进入第 ① 步：4 根线点亮，它们两端的 4 张卡亮、其余 6 张变暗；镜头放大到 `step` 卡的第 2–5 行」。
